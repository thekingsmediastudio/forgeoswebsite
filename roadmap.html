v1.0.0-alpha — All milestones complete

  • Three-tier memory system with semantic embeddings
  • Python 3.11 runtime (Chaquopy) with sandboxed execution
  • Sandboxed file workspace with snapshots and diffs
  • Headless browser + on-screen browser with shared cookies
  • Cron jobs and alarms with plain-English scheduling
  • Plugin system (.fp / .zip) — install or generate mid-loop
  • MCP client — connect to Model Context Protocol servers
  • Sub-agents — spawn and delegate in parallel
  • Companion mode with safety rails (Phase O complete)
  • Snapshots — time-travel your workspace
  • External AIDL API for other Android apps
  • Git integration (JGit) — init, commit, push, pull, clone
  • Cost meter — token and USD spend per call, session, lifetime
  • Global fallback chain — automatic provider failover
  • Light / dark theme, Jetpack Compose UI
⚡ Up next

Post-alpha — Stability & polish

  • Bug fixes and edge-case hardening from early user feedback
  • Performance improvements on mid-range devices
  • Expanded plugin documentation and examples
  • Google Play Store submission
📋 Considering

Future — Based on user feedback

  • Broader device support (lower-end hardware)
  • Additional LLM provider integrations
  • Richer plugin ecosystem and community tooling
  • Anything the community asks for and we can verify is useful

Nothing here is committed. These are directions we're thinking about, not promises.
