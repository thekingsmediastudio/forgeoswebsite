Download Forge OS

System Requirements

  • Android: 26 or higher (API 34 recommended)
  • RAM: 2GB minimum, 4GB+ recommended
  • Storage: 500MB free space
  • Processor: ARM64 (64-bit)

Latest Release: v1.0.0-alpha

Forge OS is in active development. This is an alpha release with all core features implemented and ready for external users.

Download Options

  • GitHub Releases: Download from GitHub
  • Direct APK: Available on GitHub releases page

Installation Steps

  1. Download the APK file to your Android device
  2. Go to Settings → Security → Install unknown apps
  3. Enable installation from your browser or file manager
  4. Open the APK and tap "Install"
  5. Grant permissions when prompted
  6. Launch Forge OS and complete the setup wizard

First Steps

  1. Add a Provider: Choose an LLM provider (OpenAI, Anthropic, Groq, Gemini, etc.) and add your API key
  2. Accept Permissions: Allow notifications, alarms, and file access
  3. Start Chatting: Begin a conversation with the agent
  4. Explore Features: Try the workspace, browser, plugins, and scheduling

Supported Providers

Forge OS works with any of these LLM providers:

  • OpenAI (GPT-4, GPT-3.5-turbo)
  • Anthropic (Claude 3)
  • Groq (fast inference)
  • Google Gemini
  • OpenRouter (multi-model)
  • xAI, DeepSeek, Mistral, Together, Cerebras
  • Local Ollama (self-hosted)
